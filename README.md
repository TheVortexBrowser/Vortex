# Vortex

**The gaming browser for Windows.** Free, with RAM and network limiters, built-in ad blocking, animated themes and keyboard sounds.

## Download

[Download Vortex for Windows](https://github.com/TheVortexBrowser/Vortex/releases/latest/download/VortexSetup.exe)

Works on Windows 10 and 11. If Windows SmartScreen shows a blue warning, click **More info**, then **Run anyway**. Early versions aren't code-signed yet.

## Features

- Resource limiters: RAM limit, tab sleeping and a network cap
- Ad and tracker blocking with a live counter
- Install your own themes, including animated wallpapers
- Keyboard sounds that play on web pages too
- FPS overlay, bookmarks, history, downloads and find in page
